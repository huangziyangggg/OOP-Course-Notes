## 关于本笔记

本仓库是 **Object Oriented Programming**（22EM31202C）课程的完整学习笔记，内容基于课堂 PDF 课件整理而成。所有笔记使用 LaTeX 编写，中英双语，结构清晰，适合期末复习和日常参考。
